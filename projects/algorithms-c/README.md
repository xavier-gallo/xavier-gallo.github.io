# Algorithms in C

Coursework for an Algorithms course, organized by topic: hashing, backtracking, sorting, and searching.

## Contents

- `hashing/`: hash-table exercises.
- `backtracking/`: recursive search exercises.
- `sorting-searching/`: sorting and search implementations with sample input files.

## Build

The exercises were created as individual Code::Blocks projects. Open the relevant `.cbp` file in Code::Blocks or compile the `.c` files with a C compiler. Generated binaries and IDE build artifacts are intentionally excluded.

This is academic coursework and is provided as a learning sample.
