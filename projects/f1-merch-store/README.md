# F1 Merchandise Store

Academic PHP and MySQL online-store project for Formula 1 merchandise. It includes product catalog pages, registration and login, a shopping cart, order flow, invoice page, and product administration.

The source reflects a learning exercise and has known security limitations, including plain-text password handling, a hard-coded demonstration admin check, and SQL queries that should be parameterized. Do not deploy it or use real credentials or personal data.

The public database script retains the schema and fictional product catalog, while sample account and order rows are omitted. The original database notes and course report are also omitted. A compatible MySQL schema must be prepared before running the application.
