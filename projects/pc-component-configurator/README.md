# PC Component Configurator

A Windows Forms application for selecting PC components from a SQL Server database, with separate user and administrator screens. Developed as a three-person academic project for Advanced Visual Programming.

## Requirements

- Visual Studio with .NET Framework 4.7.2 targeting support.
- SQL Server, configured with a database matching the connection settings.

The source and database scripts are included; IDE caches and compiled output are excluded. Review and configure the local database connection before running.
