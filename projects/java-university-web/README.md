# University Management Web Applications

Two paired academic exercises for Distributed Applications II, built around managing degrees, subjects, professors, and users.

## Contents

- `servlets-jsp/`: Java Servlet/JSP application with action classes, access filters, and CRUD screens.
- `rest-api/`: Jersey (JAX-RS) API with controllers, data classes, JSON parsing, and a custom API exception.

The source was created for Eclipse. Course reports are excluded. The original dependency JARs for the REST exercise are retained under its `WEB-INF/lib` directory. The Servlet/JSP archive does not include its JSP API or application server; configure a compatible JSP container before building or running that part.
