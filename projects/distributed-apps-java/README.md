# Distributed Applications in Java

Two academic exercises for Distributed Applications I, completed in a pair. The repository contains a multithreaded socket-based client/server exercise and a Java RMI version of a university-management domain.

## Contents

- `sockets/`: socket client/server implementation and protocol exercise.
- `rmi/`: RMI client and server projects.

The projects were developed for Eclipse. Compiled output and accompanying course reports are excluded. The source archives do not contain the shared `clasesdominiov3` / `edu.ucam.domain` dependency referenced by the project module descriptors and classes; provide the original course module before building or running them.
