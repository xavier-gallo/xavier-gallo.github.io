# CASOTIC

A front-end marketplace prototype for technology companies, startups, and investors, developed for an IT Project Management course. I led the project team.

## Features

- Role-based screens for users, companies, and administrators.
- Marketplace listings, company directory, and a job area.
- Spanish and English interface switch.
- LocalStorage-backed demo data and simulated authentication.

## Run locally

Open `index.html` in a browser. No server or external database is required for this prototype. All data is stored in the browser; authentication is simulated and is not suitable for real users or deployment as a production service.

The included seed data is fictional demonstration content. Do not use it as a real identity or login system.
