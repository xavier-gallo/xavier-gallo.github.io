# Documento de Arquitectura y Especificaciones: Casotic ## 1. Visión General Casotic es una red social profesional y marketplace tecnológico diseñado para fomentar la colaboración entre empresas (CENTIC), startups y grupos de investigación. ## 2. Arquitectura de Información ### Tipos de Usuarios y Permisos * **Administrador (CENTIC):** Control total, validación de KYC empresarial, moderación de contenido, analíticas. * **Empresa Registrada:** Gestión de perfil, publicación de ofertas/demandas, chat privado, sistema de negociación y valoración. * **Usuario Externo:** Consulta de contenido público, búsqueda de empresas y noticias. ## 3. Flujos de Navegación Principales 1. **Registro y Onboarding:** Registro -> Verificación de Admin -> Configuración de Perfil. 2. **Publicación de Tecnología:** Dashboard -> Crear Oferta/Demanda -> Formulario Técnico -> Publicación. 3. **Negociación:** Búsqueda -> Contacto vía Chat -> Propuesta de Colaboración -> Cierre de Acuerdo -> Valoración. ## 4. Stack Tecnológico Sugerido (Frontend/UX) * **Diseño:** Minimalista, profesional, tipografía Sans-Serif moderna. * **Colores:** Primario (#256B76), Secundario (#4A5568), Acento (#AD8B73), Fondo (#F2F4F5), Terciario (#927E5A). * **Componentes:** Cards de tecnología, sistema de filtrado facetado, chat persistente. ## 5. Roadmap de Implementación (Prototipo) * Fase 1: Landing Page y Buscador. * Fase 2: Perfiles y Gestión de Publicaciones. * Fase 3: Mensajería y Panel Administrativo.
